# Pooja's Fashion & Costume Design Portfolio

A highly modern, premium, and fully responsive portfolio website for H. Pooja, a creative Fashion & Costume Designer based in Chennai. 

## 🌟 Features
- **Sleek Aesthetic:** A dark-themed, high-contrast design prioritizing visual elegance and typography (`Playfair Display` & `Outfit`).
- **Responsive & Mobile First:** Seamlessly scales from desktop down to mobile with a beautiful full-screen slide-in mobile navigation menu.
- **Scroll Animations:** Smooth fade-up reveals and scroll triggers for an interactive experience.
- **Pure Vanilla Magic:** Built using pure HTML, modern CSS (Flexbox, CSS Grid, Clamp scaling), and lightweight JavaScript without any heavy frameworks.

## 🚀 Live Demo
The project is ready to be hosted on GitHub Pages. Once deployed, you can view the live portfolio from the environments tab on the right.

## 🛠️ Local Development
To run this project locally, simply clone the repository and open the `index.html` file in your preferred web browser, or run a local server:

```bash
# Clone the repository
git clone https://github.com/A-Generative-Slice/PoojaFDS.git

# Navigate into the directory
cd PoojaFDS

# Start a local python server
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080` in your browser.
